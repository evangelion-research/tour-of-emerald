# A Tour of Emerald

Welcome! This tour introduces the Emerald programming language through a series
of short, runnable lessons. Each lesson centres on one idea and one small
program.

## Start here

If you haven't set up Emerald yet, read
[Welcome & setup](00_getting_started.md) first. It explains what the language is
for and how to run the examples.

## How each lesson is laid out

Every lesson has the same shape:

- **The idea** — a short, plain-English explanation of the concept.
- **The code** — a complete, runnable program. It lives in
  [`code/`](code/) under a name matching the lesson.
- **What it prints** — the program's output, so you know what to expect.
- **Key ideas** — the rules worth remembering.
- **For the mathematician** *(sometimes)* — a note connecting the concept to
  familiar mathematics.

> The example programs are the same ones in [`code/`](code/), with their
> expected output in [`code/expected/`](code/expected/). If you can run Emerald,
> type them in yourself — typing a program, even a tiny one, beats reading it.
